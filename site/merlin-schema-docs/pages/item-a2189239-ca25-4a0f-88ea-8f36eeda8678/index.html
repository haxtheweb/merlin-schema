A Program is an Option with eventName: "super-daemon-run-program" and a value object containing the following keys.

value object fields

  • name (string, required) — Human-readable name shown as the program-mode title while the program is active.
  • program (async (input, values) => Promise<Option[]>, required) — The search function. input is the current search text; values is the bag passed into runProgram(). Each returned item is an Option-shaped row rendered by super-daemon-row. Re-invoked (debounced ~150ms) on every keystroke.
  • machineName (string, optional) — Stable identifier enabling runProgram('like', context, values, 'machineName') to resolve and invoke this program by name without holding a direct function reference.
  • context (string, optional) — Command context to activate when the program launches (e.g. "CMS" or ">"). A single string, not an array: runProgram() assigns it straight to commandContext.
  • placeholder (string, optional) — Placeholder text for the search input while the program is active (e.g. "Enter new title").
  • initialValue (async (values) => Promise<string>, optional) — Optional prefill: a non-empty string return pre-fills the search input when the program is launched with no explicit like/search. Currently only honored when the program is launched by machineName; selecting the row from Merlin search passes the function directly and skips it.

The whole value object is also the program's second argument (values), so any extra keys you put on value reach the program.

What a program returns

The program function returns an array of Option-shaped rows. Each row follows the same Option schema and is rendered by super-daemon-row. A common pattern is to return "confirm" rows that use eventName: "super-daemon-element-method" to dispatch a save event:

runProgram() — invoking a program programmatically

Programs can also be launched from code (not just by user search), via SuperDaemonInstance.runProgram():

When program is a string, runProgram looks up the matching value.machineName in allItems to resolve the function. The waveWand(params, target, sound) helper wraps runProgram + open() + an optional sound for the common "open Merlin in mini/wand mode near a target" interaction pattern.
